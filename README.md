# Progress wallpapers

Daily iPhone lock-screen and home-screen wallpapers generated by GitHub Actions.

- `docs/background.png` shows every day of the current year.
- `docs/home.png` shows every day of the current month.
- White dots are elapsed days, lime is today, and dark dots are future days.
- An orange dot marks each date listed in `workout_dates.csv`. When today is also a
  workout day the dot is orange with a lime ring, so today stays identifiable.
- The lock screen reports how many completed Mon-Sun weeks this year contained no
  workout at all. The week in progress is excluded, so the count only ever rises.

## Typography

Text is set in [Inter](https://rsms.me/inter/), bundled at `fonts/InterVariable.ttf`
under the SIL Open Font License (`fonts/LICENSE.txt`). Apple's own SF Pro would be the
exact match but its licence does not permit redistribution, so it cannot ship in a
public repo; Inter is the closest freely licensable stand-in.

It is a variable font, so `typography.py` sets the weight and optical-size axes rather
than vendoring separate cuts — `FONT_WEIGHT` (600, SemiBold) and `FONT_OPTICAL_SIZE`
(32, the display end) are the two knobs. Bundling the file means the workflow needs no
font install step and renders identically locally and in CI.

## Add a workout

```bash
python log_workout.py            # today
python log_workout.py 2026/11/20 # a specific day
```

Then regenerate the images and push. In a Claude session on this repo, `/log-workout`
does all of that in one step — plain English ("went to the gym yesterday") works too.

The script keeps `workout_dates.csv` sorted and unique, so a back-filled date lands in
order, re-running a logged date is a no-op, and a malformed or future date is refused.
Multiple exercises on the same date still count as one workout day.

Run locally with:

```bash
pip install Pillow
python -m unittest -v
python generate_background.py
python generate_home.py
```
