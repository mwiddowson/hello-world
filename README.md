# Progress wallpapers

Daily iPhone lock-screen and home-screen wallpapers generated by GitHub Actions.

- `docs/background.png` shows every day of the current year.
- `docs/home.png` shows every day of the current month.
- White dots are elapsed days, lime is today, and dark dots are future days.
- An orange dot marks each date listed in `workout_dates.csv`. When today is also a
  workout day the dot is orange with a lime ring, so today stays identifiable.
- The lock screen reports how many completed Mon-Sun weeks this year contained no
  workout at all. The week in progress is excluded, so the count only ever rises.

## Add a workout

Add the date once to `workout_dates.csv` using `YYYY/MM/DD`. Multiple exercises on
the same date still count as one workout day. The daily workflow de-duplicates dates
and ignores future dates.

Run locally with:

```bash
pip install Pillow
python -m unittest -v
python generate_background.py
python generate_home.py
```
